## 固定差异

| 项目 | 原迁移版 | 本版本 |
| --- | ---: | ---: |
| 每日开仓预算 | 30% | 90% |
| 最大持仓只数 | 10 | 3 |
| 单只股票预算 | 50% | 32% |
| 初始止损 | 2% | 2% |
| 止盈 | 12% | 45% |
| 普通分级移动止损 | 无 | 正浮盈提至买入价，峰值收益10/20/30/40%锁定3/6/10/15% |

峰值使用策略观察到的日线收盘价，不用最高价。当前价必须严格高于买入价才抬止损。
沿用源程序分级止损之后的涨跌停特殊保护顺序，包括该保护可能下调保存止损的行为；不擅自改成全程单调止损。
显式现金分红/送股时，峰值和成本价同时换算。价格保本不等于扣费后保本，也不能保证止损成交价。

不变项：30万本金、沪深300市场过滤、BB/RSI/MACD的2-of-3信号及评分、100股整手、T+1、固定成本、收盘信号到下一交易日开盘成交。
这仍然不是原QMT的14:50逐时重放；原资金重复扣减等问题沿用迁移版修正。

## 命令（仓库根目录）

```bash
.py311/bin/python -I examples/stock_backtesting/qmt357_commit4ac255e/run.py runtime
.py311/bin/python -I examples/stock_backtesting/qmt357_commit4ac255e/run.py test
.py311/bin/python -I examples/stock_backtesting/qmt357_commit4ac255e/run.py backtest \
  --variant-snapshot history_201910_20260928_repaired_v1 --start 2020-01-01 --end 2026-09-28
```

最后一条读取本目录`data/snapshots/`中的独立修订快照；命令本身不联网补数据。
旧股票快照仍可用互斥的`--snapshot`只读消费，两类数据都不会覆盖。
不填写 `--run-id` 时自动生成唯一结果名；已存在的结果目录一律拒绝覆盖。
`test` 包含旧版和新版全部股票测试，不运行期货/实盘测试。

## 可审计产物

每次完整回放输出汇总、年度表、每日权益、委托、成交、闭合交易、信号、市场门禁、持仓行情覆盖和 `trailing_stops.csv`。
执行前`run_identity.json`包含指定commit来源、有效参数、止损合同、输入SHA和两套源码SHA；
`code_snapshot.tar.gz`冻结启动时捕获的本地源码，manifest标明RUNNING/COMPLETE/FAILED。
失败运行保留身份和诊断但不发布绩效；启动后源码被改变则拒绝运行/发布。预热至少59个此前市场交易日。

## 边界

使用历史月度成分而非精确每日成分；价格限价及公司行动存在供应商口径限制。持仓碰到无显式行动的因子变化仍硬失败，不为跑通跳过股票。
新快照保留15处已查明有偿配股因子变化；600515/2021-12-22重整数据另有明确unsupported持仓保护，
不会把总股本扩张误记作普通股东免费获股。176处较小参考价差异未逐项公告核实，不声称输入无偏或完美。
固定佣金/印花税非真实历史券商成本；现金分红按除权日毛额到账，未重建实际到账日及分红税；送股可售日、配股与合并换股未模拟。
原始数据异常未直接碰到持仓，也可能影响信号排序，不能以账本对平证明alpha有效。
本版本是用户指定历史版本验证，不作阈值搜索或自动晋级，不影响期货正式版。
