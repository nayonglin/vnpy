## 唯一入场与退出定义

以下O/H/L/c为同一原预期下一交易日D、同epoch的有效真实bar；B=u.high，r=0.25×ATR20(u)>0、止盈距离4r。r与B均在u收盘后已知；不按D是否存在/是否成熟选择u母体，不换合约或顺延D来补结果。

- A总在O进入，F0=O，S0=O−r，T0=O+4r。
- K为D有效的buy-stop。O≥B时F1=O；O<B且H≥B时首触B进入，F1=B；O<B且H<B是真未成交，gross/net均0且费用0。
- 只在各自入场后启用S1=F1−r、T1=F1+4r，首次保护位或止盈触达退出，否则D收盘DAY退出。两边同一**距离**r/4r，不是同一绝对保护价格。无retry、roll、隔夜、q/本金或仓位竞争。
- 理想价格在D内连续，可任意往返，保护与止盈恰好触及也生效；D.open前的跨日gap仅由O计入。买stop恰在最高价触及也算理想成交；这不是tick/队列/容量或中国期货真实成交资格。
- 每个已成交完整事件减固定总预算f，主f=0.2R、同mask压力f=1R，未成交不扣。它不是历史真实券商手续费，不能用此证真实成本后现金收益。
- 缺D、非法OHLC或缺必要尺度仍为unknown，不是K未成交、0收益或坏类。D全根L/H在K入场前后不明，必须保留可行范围。

## 闭式规则

表内先写gross-R；已成交两端统一减f，未成交保持0。记q0=(c−O)/r，q1=(c−B)/r。

| A的全根触达情况 | gross区间 |
| --- | --- |
| L≤S0且H≥T0 | [−1,4] |
| 仅L≤S0 | [−1,−1] |
| 仅H≥T0 | [4,4] |
| 两者均无 | [q0,q0] |

K首先区分开盘与未成交：O≥B时与A是同一个政策结果；H<B时K为[0,0]。其余O<B≤H，F1=B，S1=B−r，T1=B+4r：

| K的情况（按以下分支判断） | gross区间 |
| --- | --- |
| H≥T1且L≤S1 | [−1,4] |
| H≥T1且L>S1 | [4,4] |
| H<T1且c≤S1 | [−1,−1] |
| H<T1、c>S1且L≤S1 | [−1,q1] |
| H<T1、c>S1且L>S1 | [q1,q1] |

理由：首次到B之前，K不承受任何保护位。H≥T1一定要求先到B，但L≤S1可以在B之前发生；只有c≤S1才在无PT分支强制入场后穿过S1。不能用全根low直接强制K止损，也不能把双触达区间整体作坏标签。

净边际区间记A=[aL,aU]、K=[kL,kU]。**O≥B时配对Δ=K−A精确[0,0]**；其余采用始终有效的外界[kL−aU,kU−aL]。这个差区间通过相同事件的可行结果作包络，不声称两端必定joint可达；不能把007/010“同一payoff、共同mask抵消”的公式直接套到不同入场。两边都成交时固定f相消，未成交K只在A一边付f，因此成本压力可能通过省参与改变差额。分别报告这一点，不能把费用预算提高后的相对改善都当触发质量。

## 两个关键反例与oracle有效性

例1：O100/H110/L99/c108/B105/r2。A确定PT=4R；K未到PT113，S1=103。路径100→99→110→108，低点发生入场前，K=1.5R；路径100→110→99→108，K=−1R。K gross必须[−1,1.5]，配对Δ为[−5,−2.5]。两边均成交，减同一f后差不变。若直接看L99≤S1103就判必止，会虚构确认入场的坏结果。

例2：O100/H110/L90/c100/B99/r2。两边O开盘进入，S98/T108相同；各自边际都可能为[−1,4]，但每条共同路径结果一致，Δ精确0。独立端点相减得[−5,5]虽包住真值，却丢失已知相同政策事实，不能据此声称确认有风险或机会。

有限BFS使用区间内O/c/H/L、B及两边SL/PT组成排序节点，相同价位合并；状态为当前位置、A active/SL/PT、K pending/active/SL/PT、是否见过H/L。开盘初始化已见极值，O≥B用共同F。只允许相邻节点往返；pending忽略K保护位，触发后才启用；同一节点的不同政策事件都处理。只有位于c且已见H/L才可DAY结算；策略已退出后市场仍继续走以满足原OHLC。

有效性来自两方向：连续价格跨节点必经过相邻节点，不存在绕过事件价位；任一有限图walk都可用分段线性连续路径实现，访问极值且终止c满足原bar。无关反复往返可按有限状态压缩，不需人为限定反转次数。节点状态有限，不需要无限枚举价格轨迹。**只按价位tag排序可缓存触达终态，不可缓存数值payoff**：DAY的(c−F)/r仍依实际价格。该保证排除盘中跳价、停板排队、离散tick、滑点及无容量成交，不能外推真实执行。

本次oracle是自写stdlib/Fraction合成脚本，无外部代码运行。固定O100、r2、4R，不作策略参数寻优；742例覆盖B在O两侧/等价、SL/PT/B/H/L/c相等、无成交/双触达及两费用，另5例显式断言。有限网格的极值均等于闭式外界仅支持边界实现，没有把它提升为全局最紧证明或新数据资格。
