## 当前真实公式：是含成本归一化，不是少算了费用

令 `M` 为真实 epoch 乘数，`N=N(u)`，政策系数为 `k`，`d=k*N*M>0`。当前 NARROW 为 `k=0.25`。070 标签核 `build_labels`（源码 135–143、215–221 行）对应：

```text
C = M * (sell_fill_stress - buy_fill_stress) - entry_fee_stress - exit_fee_stress
y = net_R_stress = C / d
```

滑点已在不利成交价中，不可从 C 再扣一次。C 使用真实退出时价格与两侧费用，只有完整模型闭合时才已知。

070 `unit_estimate`（42–50 行）在 u_close、N 和同一经济快照上估计：

```text
cu = 2 * fee_at(u_close) + BUY_slippage(u_close) + SELL_slippage(u_close)
ru = d + cu
z = C / ru = a * y
a = d / (d + cu) > 0
```

分母包含成本不等于现金费用被重复扣账；它改变的是度量单位。当前原 y 也已经是净 payoff，并非没有考虑费滑。ru 是事前预算估计，不是实际持仓损失上界：跳空、未知行情、强制退出与成本变化均可能使兑现损失超过它。

053 `stress_u_cost_R` 的构造（386–388 行）为 `c=cu/(2*N*M)`；069 明确在两种政策中沿用这套原 COMMON26。042 与 070 纯函数的 cu 都在同一 u_close 用同一 stress 费滑定义计算，成本部分不随 k 改变。因此，在**同源、同经济字段、同 stress 单位且 c 有限的接受域**：

```text
a = 1 / (1 + (2/k)*c)
NARROW: a = 1 / (1 + 8*c)
```

这不只是“完整 u 信息中可测”：在上述主 stress 域，a 已可由 COMMON 的一个现有成本列恢复。这里是源码与冻结定义推出的等价关系，**没有实际逐行新数据核验**。c 缺失或经济状态未解决时不能套公式造默认 a，不能按事后闭合状态补值。base 的 fee/tickization 和 stress 不同，不能由单一 stress c 无条件反推 base 的 a；本文不将该精确关系泛化到任意成本场景，也不提议另挑分母。

## 第一性原理：何时目标相同，何时有限模型会不同

令 X 为当前模型的事前信息，在上述可测域 `a=a(X)>0`。即使只在政策自身成熟闭合集合、并按既定训练内权重 w 学习，也有：

```text
E[w*z | X, mature] / E[w | X, mature]
  = a(X) * E[w*y | X, mature] / E[w | X, mature]
```

所以两者理想条件均值同号。逐事件 z 与 y 的正负号也相同。当前 070 `make_signals` 只消费 `history_ready20 & finite(score) & score>0`；通过后每 family 用同一 0.25%目标风险，统一缩放和整数 floor，不消费 score 幅度。若只将一个理想/冻结分数乘正 a，候选集与确定性预算路径均不变。当前主接口下不能靠换单位获得新的 oracle 选时。

若预算可理想连续使用且单笔投入风险额固定为 B，`B*(C/ru)`确有“给该交易 B 风险预算后的净现金”解释；但原条件均值乘已知 `d/ru` 就能表达同一信息。实际还有整数手、个体 cap、保证金、family 占用、不同持有期限和 D 减量，单一比率不是它们的共同充分统计。本文不据这一解释引入 score 排序或新分配器。

当前 Ridge 的函数族是固定线性头。一般 `a(X)*linear(X)` 不是同一个线性函数，因此重新拟合 z 的有限样本投影可能改变分数正负。不能说“任何实现必然完全同结果”。若令预测器形式为 `g=a*f`，平方损失会成为 `w*a^2*(f-y)^2`；而当前固定线性 g 还混入了函数族变化及相应惩罚几何，不能把新 Ridge 精确等同于旧 Ridge 只换 sample_weight。

这类差异可能有统计效果，却没有产生新市场观测；它改变了高/低成本区间及大幅 payoff 对拟合的影响。以已经反复观察的历史再选择这种投影，仍是目标/损失设计自由度。**“可能因模型错设而有差异”是诚实的局限，不足以作为本线立即重训的独立科学理由。** 此否决不宣称所有决策学习或所有标签变换无价值。

## 变换没有解决的三类识别问题

- **闭合选择与右删失。** y、z 都只在 `closed_complete_bar_model` 上有值。它们都不是所有 u 机会的无条件政策价值；D 已知取消、资金拒绝、unknown、正常开放右删失不能填 0 或负类。长持有右尾在截止点更难成熟，正数缩放既不补回它，也不修复缺价吸收的选择性。不能删掉缺 ru 行以制造更好母体。
- **成熟时钟。** u 已知分母不意味着分子提前已知。071 要求 `u<cutoff`、非空 `label_known_date<cutoff` 且完整闭合；family 并发唯一性及 u 日期权重只由当时成熟训练集计算。改成 z 不能用后来退出给过去训练补标签，也不能用最终闭合状态筛预测；NARROW 必须保留自身退出及成熟日，不能借 WIDE 的成熟样本。现有时钟保持原义，本文没有运行它。
- **组合目标和风险。** C 是一手独立反事实事件的兑现净收益，ru 是 u 的预算估计；实际 D 会重算单位风险并只减量，持仓占用和后续可行集合随策略内生变化。z 不是资金回报率、风险占用时间收益或最大回撤目标，也不含跨 family 同时损失的信息。归一化不能把极窄止损变成不怕 gap 的小损失，更不能给加注签发资格。
