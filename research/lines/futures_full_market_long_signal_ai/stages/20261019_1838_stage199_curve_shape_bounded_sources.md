## 主源调研与适用边界

1. [Boons / Porras Prado，《Basis-Momentum》正式作者摘要](https://onlinelibrary.wiley.com/doi/10.1111/jofi.12738)；[作者 NBER 会议工作稿](https://conference.nber.org/confer/2016/CEMf16/Boons_Prado.pdf)，§2 / §3。论文研究近、次近月策略的历史收益差，与曲率平均及斜率变化相关；作者提出期限特定供需压力和中介约束解释。**这不等于静态三点二阶差分有效。** 月度滚动、跨商品多空与本线单向首次退出的期限、风险暴露不同；不引用其收益为本线背书。
2. [Bianchi / Fan / Miffre / Zhang，2023，《Exploiting the dynamics of commodity futures curves》作者全文](https://arxiv.org/pdf/2308.00383)，§2.2、§4.2—4.4 / Table 5。这是日频、一日持有的多空 spread / butterfly，不能误称全部是月频。曲率 C 的三成本情景净年收益为 0.24%、−0.54%、−0.55%，后两项显著负；风险及成本后其 alpha 有时不显著。作者指出 S/C 主要由空头腿表现差驱动，后续聚焦斜率 S。**该论文给曲率交易化的是实质限制，而不是本线做多优势证明。**
3. [RBA 原始研究：风险溢价的数据与测量](https://www.rba.gov.au/publications/rdp/2017/2017-03/data-and-measurement-of-commodity-risk-premiums.html)，§3.1。收益口径为买入并持有到到期；风险溢价形状跨品种、期限不同，近端非零风险溢价通常难以统计识别。说明月份不能一概等同，但不能推出“当天便宜的月份次日必涨”。风险溢价曲线也不等于当前可观察的价格曲线。
4. [Stefan Jansen 维护者仓库的 CME futures 特征实现](https://github.com/stefan-jansen/machine-learning-for-trading/blob/main/case_studies/cme_futures/03_financial_features.py)，`term_structure()` / timing contract。实际代码用 raw_close 同日三点 `(c0−2*c1+c2)/c1`；carry 为近次月比例乘 12。维护者明确承认非月月合约的乘 12 只是缩放，未作真实期限校准。可参考同日原价、left join 保留 null 与截短数据不改变旧特征的检查方法；**不直接复制其等距曲率、窗口、clip 或收益结论。** 本轮未取得上述两篇论文的作者官方 GitHub 复现包；搜索未发现不等于不存在。

## 与当前 COMMON 的精确差别

只读核对 `tools/stage129_contract_choice_dataset.py:117–159`：COMMON 含自身 1/5/20 日等原特征、peer 一日 log return 的 mean/std/min/max、peer_count、名义 tenor span，以及同一当日选定 front/next 两合约的 `bu=log(Fnext,u/Ffront,u)`、`bp=log(Fnext,u−1/Ffront,u−1)` 和月距。期限坐标来自合约月第一天，不是真实最后交易日。

- **已包含的代数信息：** 对这对固定身份的一日相对收益，`rfront−rnext=bp−bu`。因此一日近次月 basis-momentum / slope change 不是新源；若再除同一月距，也只是既有字段变换。多月历史 BM 虽不必能从当前这行 COMMON 恢复，但改变回看长度本身不构成新的经济观测，不能因旧试验失败扫描窗口。

## 最简结构假说及明确反证

root 在本轮收口时选择后续只做 Stage200 无标签资格问题，未授权曲率训练或现金回测。对当日已观察的欲交易真实合约 j，取同一 exact product 中前后严格相邻、不同完整交割年月的有效月份 L、R；`m=12*year+month`。仅使用 Stage129 现成 u_close 正价、名义合约月第一天大于 u 的点，不增加 N、ATR 或其他归一化参数：

```
w = (m_R - m_j) / (m_R - m_L)
chord = w * log(F_L) + (1-w) * log(F_R)
q = log(F_j) - chord
```

q 越小表示目标月相对两侧名义月份插值越便宜。它不估计 Nelson–Siegel、不拟合衰减、不选三个最赚钱的月份、不需要物理仓单单位。全部报价同乘任意正换算系数时 q 不变；m 改为任何正仿射坐标时 w 不变。它只是**名义交割月份上的相对价格形状**，不是已校准真实期限的二阶导数，也不是库存、便利收益或无套利错价估计。

首尾月份无两侧、缺价/非正价均为 missing；全母体及这些动作必须保留，不因 q 缺失收缩成内侧月份幸存者，端点不外推。当天收盘价只能在发布可得后使用并影响随后执行，不得用当日已形成价格交易当日较早开盘；同日观测条件不是历史首发 PIT 字节证明。普通/F 和不同 product 不混，CZCE 完整年月/epoch 继续使用原身份。

如果未来另有一次事前冻结金融实验，主反证对象必须是上述**唯一便宜方向（较低 q）** 对既有日级净 Rstress 首次退出目标的条件增益，不允许发现方向相反后改做另一侧、换方向/月份/窗口。最低反证结构应包括：

1. 先无收益检查可用率、三点月份/间隔分布及商品/金融差异；若支持主要依赖极少产品、临交割或非流动远月，停止，不自动筛成品种白名单。
2. 只有共享同一 q_missing 的信息/无信息对照才能将数值与覆盖状态区分。COMMON52 旧分数/共同 K 基准继续作为固定参照；不能把新 missing 的控制财富冒充旧 COMMON52 复制，也不能将覆盖变化记为曲率 alpha。
3. 保留现成 COMMON 信息、成熟边界、目标、共同 K、风险、止损、成本；观察效应若仅预测相对多空价差而不能改善 long-only first-exit，假说即失败。不能以月度持有收益、横截面 spread 收益或一手独立事件和替代组合现金。
4. 在原定时间切分及 family 留出方向不稳定、主压力成本增量区间跨 0、冷启动回撤恶化等固定金融门失败，就关闭这个 q 包，不扫描曲率符号、离散阈值、邻居距离、2/3/4/更多月份、平滑或加注来挽救。

这些是金融假说的反证要点，不是完整金融实验协议。Stage200 范围仅全 action q/状态/覆盖、固定几何 fixture 及 COMMON52 相同但 q 不同的构造性 witness；没有 label/PnL/fit/cash。本子任务未实施这些计算。

## 不能支持的解释

- 合约月份不等于真实到期、最后交易、首通知或交割起止日；同月不同规则及节假日会破坏实际期限的线性插值解释。缺官方历史规则时只承认名义月距，不能补造真实年化收益。
- 等距二阶差分在不等月距上有几何偏差；即便按名义月距加权，也未消除不同交割季节、仓储、税费、质量地点、限仓和交割资格的溢价。
- 流动性、涨跌停与无成交/陈旧收盘可能制造假弯曲；日量、OI 或当日有效 K 不能证明两侧同一时刻可成交，更不证明 opening capacity。
- 静态便宜可为风险补偿或永久相对差异；不保证短期修复。曲线相对运动也可能全部发生在两侧月份，使目标做多没有收益。
- 商品存储解释不能直接扩到股指、利率/国债等金融期货；六所全市场目标不能被偷偷改成欧美 21 商品曲线研究。
- 参数更少不免除同一历史累计 421 次 fit / 226 本现金后的择题选择风险。所谓“经验直觉”只能帮助提出可反证假说，不能替代数据或将弱证据表述为高置信度。
