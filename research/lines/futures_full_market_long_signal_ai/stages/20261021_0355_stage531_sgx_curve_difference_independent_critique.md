## 恒等式先说明了什么，也没有说明什么

拟议唯一输入令 `s_m = log(SGX_m(r))`、`c_m = log(CN_m(u))`，query 月份 m、共同 anchor 月份 a：

`q_m = (s_m - s_a) - (c_m - c_a)`。

若写 `b_m = s_m - c_m`，则 **`q_m = b_m - b_a`**。这是跨市场相对基差之差，经济上涉及两个市场、两个期限的四个价格；它不是 query 在某个共同公允价格水平下的绝对折价。SGX 全曲线共同上涨 10% 而 CN 不动时，q 原值完全不变：它主动删掉最直观的共同商品方向创新。

即使额外假设 q 随后收敛，仍有三类互不等价的途径：

1. CN query 相对 anchor 上涨，但两者都跌。例如 SGX 曲线不变，CN query 跌约 9%、anchor 跌约 10%，query 相对表现改善，做多 query 仍亏损。相对收敛不等于正绝对收益，也不等于覆盖手续费、滑点和实际止损。
2. SGX query 相对 anchor 下修，CN 完全不变，q 同样可收敛。不能未经证据指定误差修正必由国内腿承担，更不能指定只由 query 承担。
3. CN anchor 单独下跌或 SGX anchor 变化，q 的信号主要来自 anchor。query 的未来上涨不是恒等式的必要组成。

因此，q 最直接对应的是相对定价/价差问题；即使一个四腿或两腿中性交易值得研究，也不能把它的经济收益逻辑移植为本线 long-only 单腿。此处没有建议另开套利线，也没有把 q 本身等同于实际可交易四腿收益，后者尚有同步、汇率、保证金和成本问题。

锚点也不是无害细节。把 anchor a 改成 a'，同一日同一共同可用集合内所有 q 都减去同一个 `q_a'`，所以纯集合内排序可保持；**零点、正负号、跨日阈值、与其他 family 的比较或缺失填 0 却不保持**。尚未冻结 anchor 和可用性策略时，不能直接给 `q>0 → long质量高` 的含义。不得按后来哪个 anchor 有利选择。

## 为什么不是一个自动成立的套利偏离

同名 YYYY-MM 不等于同一现金流。SGX 的到期指数平均与国内实物交割标的可以相关，却不具备无需证明的同物同价约束。q 中两次 log ratio 能消去共同乘法换币尺度，或两个期限完全相同的乘法转换；这不等于消掉月份相关的品质、地点、交割选择权、融资、运输、税费处理和平均窗口差异。

例如国内价即使近似为 `CN_m = A_t × SGX_m + K_m`，只要 `K_m` 是非零加法项或随月份改变，取月比值也不会消掉它。共同 K 即使不随月份改变，也一般不会从 log ratio 精确约掉。因而常驻 q、季节性 q 或某月 q 较大，可以是合同定义和现金流差异，并非 market error。这里是代数与经济可能性，不声称本次已识别具体多少 q 来自哪项成本。

品位和定义改变不只影响价格水平：若与月份/到期身份相关，也会直接改变曲线。Stage528 已明确 2026 指数身份应按 **expiry** 切分，不能按报告年份粗接；本 stage 没有重新认证历次 DCE 品质/品牌制度或 2019 每个月的 SGX 结算方法。

## 开盘已经支付的部分与剩余收益

保守 `r → 完整 u → D` 时钟的优点是避免把未知发布时间硬贴入当晚；代价是 CN 已有一整日乃至更多时段吸收外部信息。外部新观测仍可能有残余价值，但不能继续称它是国内休市期间尚未处理的最新冲击。

从 `u.close` 到 `D.open` 的重新定价也可能吸收剩余差异。若后来做实证，能够证明的是从 **实际 D.open 成交后** 到既定退出的净收益，而非 `u.close → D.open` 跳空解释率、q 回归系数、价格发现份额或未来价差收敛。日线 `D.open` 可能来自前工作日夜盘，不能改称 09:00。把 gap 当入场后利润是测量错误；但本次没有数据结果，因此也不能先断言实际 q 的全部信息必然已在开盘消失。

当前缺口是：为什么在这一消费延迟和实际开盘之后，**CN query** 更可能继续上涨，且收益足以支付成本；不是要求完美 PIT 或无风险必赚的理论证明。当前已读官方规则和研究没有补上这个相对信息到单腿方向的桥梁。
