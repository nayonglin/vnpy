# Stage001 国内产业数据、金融终端与交易所原始数据独立调研

- 研究线：`futures_fundamental_data_sources`
- 调研时间：2026-11-08，阶段文件使用主 agent 指定的 15:00 时间标记。
- 范围：公开官方产品、开发者文档、官方方法论与历史报告；未登录、未购买、未安装依赖、未调用付费接口，未跑回测、未修改策略和交易配置。
- 开始反思：本次不是参数调优，不构成收益驱动的过拟合；有继续价值，因为决定未来 Skill 是否能获得可信、可追溯、具备历史时点的数据。
- 结束反思：仍不是策略效果证据；继续推进采购样本验收有价值，但仅凭品牌历史或“20 年积累”不能开始声称 2015 年起可做严格历史判断。

## 一、结论与采购优先级

判断：以稳定性和历史完整度为优先，先评估“一个通用金融数据骨架 + 按商品族选产业原始源”，不宜一次购买多家功能相近的通用终端，也不能把交易所仓单当社会库存的替代。黑色优先钢联/Mysteel MDS；有色优先 SMM；能源化工优先评估隆众（与钢联数据存在产品整合）和卓创，并按同一组指标做样本比对后选一家主源。Wind / iFinD / Choice 适合统一宏观、海关、金融价格与元数据；通用终端对第三方产业指标的收录、历史长度和授权必须逐项核验。

这里的“优先”是本次调研后的采购建议，不是已实测的可用性排名。所有厂家公开材料均不足以证明“所有中国商品的关键基本面序列完整覆盖 2015—今天，且能返回初次发布版本”。未取得正式报价，不提供市场传闻价格。

## 二、证据等级

| 等级 | 含义 | 本次状态 |
|---|---|---|
| P：官方产品/文档 | 官方确有该接口或交付方式，不能等同本账号权限 | 钢联、SMM、卓创、隆众、Wind、iFinD、Choice 已有 |
| M：官方指标元数据 | 某个序列的起始日、频率、来源有明确目录记录 | SMM 若干铜指标已找到；Choice 支持查询这些字段 |
| H：官方历史实例 | 官方旧文章或报告证明某时期曾有指标，不证明全历史可导出及完整 | Mysteel 2015 数据、隆众 2015—2019 报告目录 |
| X：授权样本实取验收 | 用目标账号导出并检查断档、修订、发布时间、许可、SLA | 本次均未做 |

## 三、值得重点评估的产业源

### 1. 钢联数据 / Mysteel / MDS：黑色主源候选；隆众有整合关系

[MDS 官方产品页](https://mds.mysteel.com/)明确支持 API 定向提取及大批量数据同步推送；落地库服务会在客户服务器部署映射终端，实时更新客户购买的数据。官方声明覆盖钢铁、能源、有色、化工、橡胶、农产品等，并采用标准化数据表。证据 P；公开页未给出逐指标最早日期、API SLA、失败重放、修订历史字段或固定报价。

[钢联数据帮助](https://www.steelphone.com/2017/data/help/sywt/)说明终端包含 Mysteel 的价格、库存、调研历史及最新数据，还包括网站未发布的成交量数据。这能支持“终端并非只整理公开网页”；不能推出每项指标均自 2015 年存在。

历史实例：[2015 年建筑钢材回顾，2016-01-18 发布](https://gc.mysteel.com/16/0118/15/B40C11362B2796F9.html)确有 2015 年主要城市建材社会库存及原料库存图，来源为钢联数据（H）。采购时应要求相应序列原始导出、指标 ID、样本口径和 2015 全年明细，不能仅购买图表或年报。

必须保留版本口径：[2024-10-23 官方通知](https://mfs.mysteelcdn.com/group1/M00/E1/72/rBL64GcYi-SAR-mdAAKMGq9T3Yk433.pdf)说明自 2025-02-13 调整铁矿石港口库存发布，47/45/41/31 港总量仍保留，分港数据取消并改区域发布。长期总量与细分粒度不能混为一谈，历史分港表也未必能按原接口持续更新。

必须保存初值：[2023 年 3 月铁矿石数据汇总](https://tks.mysteel.com/23/0404/13/7037D0BA88687C3C.html)明确：45 港到港月度数据先出初值，下月更新上月终值；铁水等月度值由周度均值及天数构成，库存月度值取最接近月底的一期。Skill 应区分实际月产量、周值折算月量、月末快照；不能把今天下载的终值当作当时已知值。

### 2. SMM：有色主源候选，公开元数据最便于先做历史清单

[SMM 数据库 PRO](https://data-pro.smm.cn/introduce)明确提供 Excel 插件、一键增量更新及 API；页面还给出铝社会库存消费天数、锌加工费等业务口径。特别是锡锭社会库存示例明确从 2020 年 1 月开始，不能用“20 多年积累”推断覆盖 2015（P/M）。

SMM 已有[官方 MCP Data-feed](https://mcp.smm.cn/)，并提供[官方接入指南](https://mcp.smm.cn/guide)：先申请套餐权益、再生成密钥；推荐 Streamable HTTP，单一端点 `https://datapromcp.smm.cn/mcp`，请求头为 `api_key`。这使其成为可直接适配智能体的候选，但本次没有密钥，未核验工具列表、单次历史返回上限、时间戳字段和稳定性。MCP 是接入协议，不能替代对历史库和许可的验收。

公开铜目录给出以下**精确起点**（M，表示目录声明，尚非 X 实取验收）：

这类目录非常有价值，但页面的结束日期可能是页面维护日期，不等同最近一个真实观测期，更不等同首次发布日期。官网部分数据库介绍还有较旧宣传文案，采购必须看真实样本。

[SMM 1#铅价格方法论](https://static.smm.cn/comp.smm.cn/2.0.9/static/comp.smm.cn/pdf/v2/cn/SMM1%23%E9%93%85%E9%94%AD%E4%BB%B7%E6%A0%BC%E6%96%B9%E6%B3%95%E8%AE%BA.pdf)写明具体采价与发布时间段，并存在错误更正政策和发布后勘误；该方法论同时要求商业分发取得明确协议。因此应单独核验 AI 分析、云模型传输、内部历史落地、备份留存、对外报告引用等权利，不能把终端查看权解释成所有机器用途的授权。

### 3. 隆众与卓创：能源化工要按装置、原料路线和库存环节选源

[隆众石化数据中心升级通知](https://www.oilchem.net/23-0704-14-166ff3a69cde3cff.html)正文署名 2022-10-08，说明原正式客户权限转为隆众石化行业数据终端（即钢联数据终端）相应权限，新中心为 `https://dt.oilchem.net/home`。外层页面标注发布时间却是 2023-07-04；这是**迁移页面时间不等同事件时间**的具体例子。购买钢联、隆众前先查是否重复付费，不能推断 MDS 合同自动含所有隆众数据。

[隆众终端页](https://app.oilchem.net/advert/terminal.html)展示价格、资讯、产业链数据、周月报告等交付（P）。[隆众 2019—2020 沥青年报目录](https://a1static.oilchem.net/lzjh/report/year/201920205645453.pdf)包含 2015—2019 厂家库存；[纯苯年报目录](https://a1static.oilchem.net/lzjh/report/year/2019202045485746.pdf)包含同期香港库存（H）。目录不是结构化全历史已交付证据，也不能推广到其他化工品。

[卓创数智官方页](https://digital.sci99.com/)列出价格、装置工艺、供需、库存、成本利润、贸易流向、船期等数据，覆盖产业研究；[官方公司介绍](https://corp.sci99.com/)列出价格下载、产业数据包、数据定制等；[数据中心](https://datacenter.sci99.com/cn/)公开展示数据包可通过邮箱、卓创云、API 接收（P）。公开材料未给每个期货品种最早起点与修订库保证，需索取 API 文档、样本和正式授权，不因为公司已有 20 年一手积累就称全部指标自 2015 可得。

### 4. 百川盈孚、Datayes：保留询价候选，现有公开证据不够同档排序

[百川行业大数据系统](https://dsj.baiinfo.com/home/tourist)存在公开入口并显示 API 选项，但本次页面读取受限，未拿到可核验的公开接口规范、逐指标起点、新闻历史范围或 PIT 字段，不把它写成已证明与上述产品等价。

Datayes 官方文档入口 `https://apidoc.datayes.com/` 本次返回 502；未找到足以证实目标中国商品产业指标全覆盖的官方公开文档，故不以其传统行情/财务数据能力替代产业调研源。可候选询价，但先提交同一指标清单，避免因品牌或数据市场标签就认为满足要求。

## 四、通用终端与产业源怎样互补

### Wind

[Wind 官方主页](https://www.wind.com.cn/portal/zh/Home/index.html)确认 EDB 宏观行业数据可在终端和 Excel 动态提取；[WDS 官方产品](https://www.wind.com.cn/portal/en/WDS/index.html)确认 Filesync 落地库、API、Excel 插件等通道，支持宏观、金融、新闻等业务（P）。公开文档不证明具体钢联/SMM/隆众指标均随标准包附送，也未证明每项具备 2015 初值库。

判断：优先把 Wind 放入“宏观/跨市场骨架”竞品评估，可节省统一代码和元数据工作；产业数据是否已含、能否导出及重复收费需单独逐项确认。桌面 Client API 与服务器数据服务不应在采购方案中混用。

### iFinD

[官方 FAQ](https://quantapi.10jqka.com.cn/gwstatic/static/ds_web/quantapi-web/help-center/faq.html)明确数据接口是独立衍生产品，支持 Python 等 SDK 及 HTTP；试用与正式账号历史年限可以不同。文档提示行情多在收盘后 1—2 小时入库，公司公告新闻等常在夜间入库，因此原站时间不等同接口可得时间。

[官方 THS_EDB 手册](https://quantapi.10jqka.com.cn/gwstatic/static/ds_web/quantapi-web/help-center/manual.html)提供按指标 ID、日期范围请求宏观行业数据，且参数列有更新起止时间；这可用于调研增量机制，却不自动证明有全部历史修订版本（P）。不要把 SuperMind 股票策略 API 当 iFinD 商品基本面接口文档。

### Choice

[官方量化接口手册](https://quantapi.eastmoney.com/Upload/EMQuantAPI_Python.html)明确提供 `edb`、`edbquery` 和历史资讯 `cfn`。元数据含来源、单位、频率、起止日、更新时间。`IsPublishDate=1` 仅对**部分 EDB 指标**能返回真实发布日期；发布日期仍不保证历史初值。资讯字段 `datetime` 是展示时间，部分盘后公告会展示为下一交易日；`eitime` 为生产时间，公告该字段仅 2017 年起且只有日期。它们不宜直接当秒级首次公开时间（P）。

判断：Choice 的公开字段限制说明清楚，可作为同一采购清单的有力竞品；“有发布日期”不能被写成全库 PIT。Wind / iFinD / Choice 的最终比较应以目标指标命中率、真实历史缺口、修订版本、自动化授权与故障恢复验收为主，而不是指标总量。

## 五、交易所仓单与库存：权威原始源，但交付稳定性要单独工程化

[上期所日周数据页](https://www.shfe.com.cn/reports/tradedata/dailyandweeklydata/)明确同时有仓单日报、库存周报。两者是不同表；SHFE、INE、DCE、CZCE、GFEX 也不能直接拼接手数和吨数。注册仓单不是全部社会库存；有效预报、厂库信用、保税仓库和完税仓库也要保留各自类别。

本次公开网页访问结果：上期所栏目可读取，但直接历史数据文件未能经 web 工具打开；郑商所栏目返回 412；大商所及广期所部分入口超时。**这只证明本次抓取途径受限，不证明交易所数据内容不可靠，也不证明数据不存在。** 未实取 2015 全年官方原文件，因此不认证交易所全历史完整度。

官方查询入口：

- SHFE：[日周数据](https://www.shfe.com.cn/reports/tradedata/dailyandweeklydata/)。
- CZCE：[仓单日报](https://www.czce.com.cn/cn/jysj/cdrb/H770310index_1.htm)。
- DCE：[仓单日报](http://www.dce.com.cn/dce/channel/list/187.html)。
- GFEX：[仓单日报](https://www.gfex.com.cn/gfex/cdrb/hqsj_tjsj.shtml)。

开源适配器只能作为端点和格式变迁的工程证据：[AKShare 维护者的仓单源码](https://github.com/akfamily/akshare/blob/main/akshare/futures/futures_warehouse_receipt.py)记录 SHFE 自 2025-11-18 改用分品种 HTML，旧 JSON 文件不再提供；CZCE 的导出格式有 xls/xlsx 分界；DCE 程序访问可能遇到 412。并非三个交易所都存在持续稳定、正式承诺的匿名 REST API；开源工具适配成功也不是商业 SLA。上述变化需要版本解析器和原文件留存，不能用“重试三次”解决所有结构变化。

建议：交易所原表作为溯源锚；付费数据库承担每日增量、断档补发和统一查询。通过商业源获取的同源仓单与交易所原表不算两个独立经济证据。未上市品种不存在 2015 仓单属于市场结构事实，不应补零。

## 六、商品族指标必须分开定义

以下为本次研究判断及待采购清单，不代表每家产品均已承诺覆盖：

| 商品族 | 更值得付费的实证环节 | 不宜混用的口径 |
|---|---|---|
| 黑色、铁矿、煤焦 | 港口分矿种库存/疏港/到港/发运，钢厂铁水和利润，钢材厂库社库与成交 | 31/41/45/47港、64/114/247家样本；周值折算月量与真实月度调查；终值与初值 |
| 铜铝锌镍锡等 | 冶炼/下游开工、产量检修、加工费、升贴水、进口盈亏、分环节社库 | 原矿与精矿，TC与金属价格，仓单与社库，样本库存与全社会，含税/币种/地区/品牌 |
| 能源化工、橡胶 | 分装置产能利用率和检修、港口/厂库/贸易商库存、不同原料路线利润、下游负荷 | 开工率与产能利用率，油制/煤制利润，国内/保税货，设计产能与有效产能 |
| 农产品 | 作物年度供需、压榨/油厂开机、到港、港存、养殖/饲料需求、天气和政策 | 自然年与作物年度，商业/工业/国家储备库存，检验量与真实消费，国产/进口品等级 |

## 七、正式采购前必须拿到的样本与合同答复

1. 先交目标商品、20—50 个核心指标清单，逐项给指标 ID、数据所有者/采集者、定义、样本数量与变更史、单位、频率、起点、末期；“2015 年至今有数据”必须落实到每个序列。
2. 对 2015、2016、2020、2022、2026 各拿一整月原始样本，另拿两个政策/供应冲击周，核查覆盖、缺失、零值、口径断点和接口返回上限；要求完整缺口清单。2015 对未上市合约不作为硬指标，但现货产业数据是否存在仍要分开核验。
3. 每条记录分别要求观测期、原始发布时刻（含时区）、供应商入库时刻、抓取时刻、修订时刻和版本号；能否取“截至某时刻当时已知值”，能否提供初值、修订值、删除/撤稿记录。只有日期且没有时刻时须披露。
4. 新闻要求原文正文、标题、作者/原始机构、原始 URL、首次发布、更新时间、供应商接收时间、稳定 ID、重复转载关联；抽查 2015 全年档案密度。检索结果中有旧文章并不等于有完整新闻历史授权。
5. 交付明确选 API、服务器 API、桌面 SDK、落地库、Excel 或 SFTP；确认操作系统、Python 3.11、无人值守、并发、日/月流量、批量回补、增量游标、失败重放、服务中断补发和历史再下载。
6. 合同明确 API 与终端模块、第三方产业源附加费、并行账号、机器数量、内部落地/备份留存、到期后历史保留、模型推理输入、云端传输、生成摘要、对外分享、衍生结果引用的权利；不外推查看权限。
7. 询价统一按“指定指标 + 历史范围 + 增量 + 数据接口 + 许可”组合，避免用公开终端年费推算真实研究成本。此次未发现足以负责任给出当前统一价格的官方价目表。

## 八、调研置信度与下一步

对主要源的交付方式与上述明确字段限制，置信度较高；对完整历史、历史首次发布时间、真实 API SLA、全部修订版本、采购成本，置信度不足，必须进入 X 级样本验收。本次不把商业宣传的“稳定、可靠”变成实测结论。

下一步最有价值的是把仓库目标商品整理成固定指标表，同时向钢联（含隆众权限划分）、SMM、卓创和 Wind/iFinD/Choice 递交同一份样本验收要求，再决定最小采购组合。无须先做策略参数搜索，也无须为了满足 2015 起点强行用不等价指标补齐。
