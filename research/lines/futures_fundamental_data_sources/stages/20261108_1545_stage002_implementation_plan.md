# 免费期货基本面 Skill 实施计划

> 执行方式：主agent在当前研究分支实施，来源搜集与最终审阅并行；用户已要求“开始做、免费来源、做完分析焦煤”，不另设确认步骤。

**目标：** 创建可发现的 `futures-fundamental-bias` Skill，使用免费公开来源给出可追溯、有反证和数据边界的中国商品基本面判断，并真实分析2026-11-08焦煤。

**依据：** 用户本轮指令与Stage001来源调研；本轮“免费”覆盖此前可付费的偏好。

**方案：** 精简SKILL入口＋免费来源目录＋商品族手册＋证据契约＋Python标准库审计助手。联网检索使用宿主web工具，不造未经验证的统一免费接口；助手只查时间、访问状态、去重与证据覆盖，不计算多空分数、不执行交易。

## 约束与审阅重点

- 唯一维护位置 `skills/futures-fundamental-bias/`，发现入口 `.agents/skills/futures-fundamental-bias -> ../../skills/futures-fundamental-bias`。
- 使用`.py311/bin/python`，不新增依赖、不读取凭证、不安装第三方Skill、不提交/推送、不改其他策略。
- 只用免费公开正文/摘要；付费正文、搜索摘要、无来源传闻不能冒充已读原文；公开摘要可按其实际可见范围入证。
- 日期必须含真实发布日与观测期；当前分析排除截止后发布、陈旧、不可访问和误品种事实。仅有日期的发布按次日零点保守视作可用，披露精度。
- 焦煤、焦炭、动力煤分开；同源转载去重；不同样本保留矛盾，焦炭提涨意向与落地分开。
- 2015逐指标覆盖仍待核，不宣称已有完整历史数据库或严格PIT回测资格。
