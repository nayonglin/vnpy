# futures_range - 期货震荡策略

## 定位

- 资产：商品期货。
- 策略类型：震荡/区间回归。
- 当前状态：独立研究线。
- 隔离要求：不得修改第78趋势策略及其配置，不与趋势策略直接混合。

## 最近关键阶段

- 第199阶段：全商品统一双向震荡 v10 扩容验证。
- 核心结论：
  - 已新增56个可交易商品、排除CFFEX的独立v10入口，统一允许long+short，继承v8参数。
  - 同口径fresh A/B：Core4 v8为`210,820 / 5.41% / -1.98% / Sharpe 0.564`；全商品v10为`204,120 / 2.06% / -15.58% / Sharpe 0.054`。
  - v10新增52品种合计净PnL`-9,140`、滑点`23,930`、成交`1,139`，扩容没有形成正贡献。
  - 决策：拒绝全商品统一双向v10，保留Core4 v8为内部基准，不进入正式或趋势组合。

## 当前判断

- 商品反转不具备跨品种无条件普适性；统一全市场扩容显著放大交易成本和回撤。
- 不能根据本次亏损名单后验剔除品种、方向、年份或调阈值，否则会把一次证伪改造成选样过拟合。
- 全市场入口仅保留为可复验的负向基准；Core4 v8仍是震荡路线内部基准，不是正式策略。
