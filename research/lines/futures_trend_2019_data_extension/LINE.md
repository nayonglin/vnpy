# futures_trend_2019_data_extension - 期货趋势2019数据延展线

## 定位

- 资产：商品期货。
- 上游策略：当前期货趋势策略及 Stage757/正式链路。
- 研究目标：验证能否把当前回测从 `2020-01` 可信延展到 `2019-01`，并明确需要补哪些连续主力/真实合约日线数据。
- 独立性：本线只做数据可用性、数据修复和只读回测验证，不修改正式配置，不连接 CTP，不调用下单。

## 研究假设

- 当前 vn.py 数据库有 2015-2019 真实合约日线，但当前策略直接使用的品种连续序列大多从 `2020-01` 开始。
- 若要从 2019 开始跑当前策略，不能直接修改 `START_DT`；必须保证：
  - 2019 每日主力映射存在；
  - 映射到的真实合约日线存在；
  - 连续指标序列或产品连续 bar 存在并满足预热窗口；
  - 后上市品种按真实可交易日期加入，不提前参与 AI 池/信号。
- 2019 延展是稳健性验证，不应根据 2019 结果反向调参数。

## 反过拟合约束

- 不因为 2019 某段表现好/坏而调整交易规则、品种池、AI topN 或风险倍率。
- 不把缺数据导致的无交易当成策略收益或稳健性证据。
- 不把后来上市的品种提前放进 2019 池。
- 数据修复优先补齐可审计的合约日线和映射，策略逻辑保持冻结。
