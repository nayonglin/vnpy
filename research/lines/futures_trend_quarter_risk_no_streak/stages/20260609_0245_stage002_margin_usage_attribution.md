- 全周期保证金占用：
  - A 平均 `19.4470%`，中位数 `16.7091%`，p95 `55.0005%`，最大 `79.6015%`
  - C 平均 `7.2272%`，中位数 `3.6131%`，p95 `27.4386%`，最大 `54.7105%`
  - A 保证金大于 `30%` 的天数 `475` 天，C 只有 `47` 天
  - A 保证金大于 `50%` 的天数 `133` 天，C 只有 `4` 天
  - A 保证金大于 `60%` 的天数 `50` 天，C 为 `0` 天
- 活跃天数和交易：
  - A 保证金大于 `0` 的天数 `1055/1532=68.8642%`
  - C 保证金大于 `0` 的天数 `956/1532=62.4021%`
  - A 交易 `633`，C 交易 `524`
- 年度绝对保证金：
  - 2020 A 平均保证金约 `65,540`，C 约 `32,665`
  - 2021 A 平均保证金约 `177,294`，C 约 `34,537`
  - 2023 A 平均保证金约 `418,474`，C 约 `15,071`
  - 2025 A 平均保证金约 `829,853`，C 约 `40,294`
  - 2026 A 平均保证金约 `1,605,520`，C 约 `27,774`
- 公式归因：
  - 策略手数先算 `risk_amount = limited_balance * risk_ratio * risk_multiplier`
  - 再用 `contracts_by_risk = risk_amount // risk_per_contract`
  - 最终手数取 `contracts_by_risk`、`contracts_by_margin`、单笔上限、最大手数等约束的最小值
  - C 把 `risk_multiplier` 从 `0.80` 改成 `0.20`，同样止损距离下 `contracts_by_risk` 天然约为 A 的四分之一
  - 因此 C 的问题不是保证金不够，而是风险预算先被砍小，很多信号只能开很小或被整数手约束压掉
- 收益断崖归因：
  - C 不是简单少赚四分之一，而是早期复利底座没起来：C 2021 年末 `466,130`，A 为 `1,082,930`
  - 到 2025 年，A 已用大权益参与右尾，年度赚 `4,429,245`；C 只赚 `176,460`
  - 所以收益从 `4264.1425%` 降到 `171.9200%`，核心是风险预算过小 + 整数手/止损距离约束 + 早期复利断裂叠加
