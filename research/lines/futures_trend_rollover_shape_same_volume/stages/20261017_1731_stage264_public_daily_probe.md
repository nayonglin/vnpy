# Stage264 公开备用日线源小样本探测

- 研究线：`futures_trend_rollover_shape_same_volume`；执行时间：2026-10-17 17:27—17:31 CST。
- 类型：只读真实数据可得性与质量探测；不是重要突破版本；不训练、不回测、不修改正式源码/配置/AI池/LINE/registry，不写主数据库，不读取私有凭证、不安装依赖。
- 开始判断：没有按收益选样或参数寻优，当前不属于选参型过拟合；检验真实合约主力前历史有价值，不能据此假定AI有效。

## 公开调研与接口判断

- 先读取研究线索引、Stage264预声明计划，以及 [Akshare 官方 GitHub 的 futures_zh_daily_sina 实现](https://raw.githubusercontent.com/akfamily/akshare/main/akshare/futures/futures_zh_sina.py)。按其原始URL与`symbol`、`type=2021_04_12`参数发普通GET，不改造成连续合约，不绕访问控制。
- [EDB 官方文档](https://doc.shinnytech.com/edb/latest/md_server.html)给出`https://edb.shinnytech.com/md/kline`，日线`period=86400`可无需token，但历史预计从2021-01-01起，不能把“任意历史区间”理解为必有2015数据。只做一次真实2015合约请求。
- 共6次公开服务GET，间隔1秒，连接/读取timeout为10/30秒，无鉴权、自动重试或权限绕过。最初沙箱DNS连接失败没有到达服务；通过已授权网络执行完成正式6次探测。空响应不重试。

- 242行中0个重复日，1个OHLC异常：2019-04-30 `open=4192/high=4198/low=4187/close=4184`，收盘低于最低；有效唯一价格日241。

- 同品种主力映射交易日历在返回首末日内有243个交易日，公开响应242日，缺2019-04-22；返回日期无日历外日期。这里使用本线2015—2019映射日历，不能替代2014或上市边界的交易所证明。
- 2018-12-03—05三个抽样重叠日成交量/OI均与本机相同；只记录原始单位，未对2020年前双边/单边口径做转换或普遍一致性断言。

## 决策与结束反思

- 公开小样本没有取得任何2014/2015老合约前史，不能进入Sina/EDB的2015批量。2019控制说明Sina可能补部分较新交割月前史，但当前样本有质量硬问题，须独立复核与另行限定合同后再决定，当前不批量。
- 结束过拟合判断：否，未按收益调参、选策略或造样本；仍需防止只挑有覆盖的较新合约并把结论外推到2015。
- 继续价值判断：继续有界核验已授权TqSdk普通serial或其他合法数据来源有价值；对当前两个公开端点反复换参数/重试2015的价值低，停止本公开探测分支，不恢复依赖缺失数据的训练或回测。
