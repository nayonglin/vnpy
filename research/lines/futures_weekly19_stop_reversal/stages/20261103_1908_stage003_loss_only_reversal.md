# Stage003 仅亏损原仓触发反手

A 为 Stage002 已独立审查的正式 m0007，C 为同阶段无原仓损益筛选的反手版，D 为 C 加严格亏损准入。冻结同一 2015-01-01 至 2026-11-03 历史输入、19 品种、15 万交易账户加 15 万备用金及全部既有保护、风险、成本和次交易日开盘代理。旧 A/C 不重算，D 自 2015 冷启动完整重放。反手单仍依赖原仓实际全平成交且执行锚位于原执行周。

只新增 D 的原仓净损益门。以同一物理合约本次从空仓到全平的全部真实模拟成交为一个周期，纳入先前部分平仓、开平滑点及模型手续费。以全平成交后的净额严格小于零为通过，打平与盈利均拒绝。换月后的物理合约单独起算。D 以成交账本而非信号价或组合当日盈亏判断。三类原仓止损继续有效，反手仓技术止损继续无均线条件。A/C 参数和历史结果原样保留。

假设为本金已亏损的止损比盈利回撤更可能对应原方向判断失效。此筛选在看过 Stage002 同历史结果后提出，样本内过拟合风险为是。结构差异足以做一次固定全历史验证。对比 D 相对 C 的反手腿与组合差异，晋升判断依然以 A 为基线。研究设计参考了 [Kaminski 和 Lo 的止损研究](https://dspace.mit.edu/entities/publication/bb69ca4b-0cdc-487f-831d-63b2e84fafee) 和 [vn.py 组合回测成本账本](https://github.com/vnpy/vnpy_portfoliostrategy/blob/main/vnpy_portfoliostrategy/backtesting.py)。前者支持检验路径依赖，不能直接证明反向入场的有效性。
