# Stage057 十品种跨类别低相关筛选设计

2026-11-05 13:04 上海时间。line_id 为 `futures_weekly_two_close_momentum`。用户要求精选十个品种，覆盖品类，高相关品种不能并存。本阶段只选择名单和验证相关性，未授权新增财务回测。研究性质为母池敏感性后的结构化选池，不判重要突破。

## 作者固定的范围与规则

沿用当前 S21 母池与截止 2026-11-04 的冻结行情。以下为研究用主要风险分类，包含作者分类判断，不声称覆盖母池外的粮食、原油等全部期货产业子类。十个名额无法覆盖每一条细分产业链。每类恰好一个。

| 类别 | 候选 |
| --- | --- |
| 贵金属 | au.SHFE |
| 有色金属 | cu.SHFE |
| 黑色产业链 | jm.DCE、SM.CZCE、rb.SHFE、hc.SHFE、ss.SHFE |
| 能源 | fu.SHFE |
| 化工及工业材料 | MA.CZCE、FG.CZCE、SA.CZCE、SH.CZCE、lc.GFEX、si.GFEX |
| 油脂 | OI.CZCE、p.DCE |
| 纺织 | CF.CZCE |
| 畜牧 | lh.DCE |
| 果品 | AP.CZCE |
| 林业及天然材料 | ru.SHFE、sp.SHFE |

固定阈值为相关系数绝对值小于 0.60，属于作者预设的研究界限。三种口径分别是最近 252 个交易日日对数收益、最近 756 个交易日日对数收益、最近 156 个完整交易周的周对数收益。日频共同样本分别至少 180、500，周频至少 100；不足即不能入选。周频必须该周所有实际交易日有效，缺失不补零，当前未完成周排除。

每日使用当日主力对应的物理合约，在本交易日与前一交易日的同一物理合约收盘价之比取对数。主力变更时仍使用同合约的前收盘，避免主力拼接价差制造相关性；这是截至筛选日已知行情的描述性检验，不是可交易收益或策略账本。

三种相关性各取绝对值，任意一对的筛选分数为三者最大值。枚举全部 5×6×2×2=120 组各类一个的候选，先要求 45 对均符合固定阈值，再选择最大分数最低者，其次平均分数最低者，完全相同则按名单字典序。若无合格组合，保留失败，不临时放宽门槛。全历史和滚动 52 周相关性只做诊断，不用于调参或换样。

不使用 Stage056 品种 PnL 或任何策略收益排名参与选择。本阶段只参考收益序列的共同变化，没有计算新策略财务结果。固定一手不等风险，相关性也不约束单手保证金或波动金额。

## 外部调研与判断

商品存在跨板块分散机会，相关性会随时间变化，应同时检查多个观察窗口。[CME 原始研究](https://www.cmegroup.com/articles/2025/exploring-diversification-within-commodity-markets.html)

公开代码中有 Pearson 和绝对 Pearson 等相关性度量，本次使用容易复核的绝对 Pearson 作为双向策略的保守结构限制。[Riskfolio-Lib 源码](https://github.com/dcajasn/Riskfolio-Lib/blob/master/riskfolio/src/AuxFunctions.py)

## 运行前反思

过拟合判断为否，本阶段预先固定分类、窗口、阈值与目标，只按分散性选池。若用该名单再解释 2015 至今的历史收益，会有事后选池偏差。当前母池本身也继承历史筛选背景。

继续价值判断为是，可得到与按盈利挑品种不同的结构化候选，并明确目前能量化验证的相关性边界。历史低相关无法保证未来或压力期始终低相关。
