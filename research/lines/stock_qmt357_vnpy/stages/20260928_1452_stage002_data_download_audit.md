## 本次实现与验证

新增 `baostock_download.py` 和 `tests/test_baostock_download.py`；加强 `data.py`/`tests/test_data.py` 保留源元数据。对外入口为：

```python
from baostock_download import download_panel
from data import prepare_snapshot, load_snapshot

source = download_panel(start="20231001", end="20251231")
snapshot = prepare_snapshot(source, "unique_snapshot_name", universe_mode="historical")
panel, manifest = load_snapshot(snapshot)
```

上述导入示例仅用于股票专用目录内的受控入口，不指示绕过运行器的隔离措施。已经发布 READY 的源不能为了重复演示而覆写。

- 每月月底完整历史成分快照从 2023-09 起下载；每份必须恰好 300 行、300 个唯一合法证券，无缺失或未来 `updateDate`。快照严格在查询日之后生效，不提前到供应商 `updateDate`，也不在同日生效。
- 对历史成员并集只应用原策略排除 `300`、`688` 的筛选，不按结果选股。保留 `301/302`，因此不得称其为纯主板池。
- 原始未复权日线、累计后复权因子、各年分红分配响应分别缓存。因子只按当时已生效日期向后匹配；早期缺因子用 1，不从未来向前填充。
- 使用税前每股现金与送转股份倍率；公告经济内容相同的重复记录只去重，冲突同日记录拒绝。现金及新增股份以除权日可用作简化；未模拟红利税、到账日差异、配股、复杂换股、权证与其他公司行动。
- 暂省略 `tradestatus=0` 的不可交易原始行，原始缓存仍完整保留。下面明确记录这一实现会遗漏停牌日现金行动；不能把缺 bar 等价为没有股东权益事件。
- 限价是 `preclose` 和板块/ST规则推算，不是交易所真实历史逐日限价。主板普通 10%、研究期主板 ST 5%；`sz.3*` 自 2020-08-24 起 20%，包含 ST，保持原策略股票池不变。价格按 Decimal 四舍五入至分，不用二进制浮点中间乘法。
- 官方依据：[深交所创业板交易制度说明](https://investor.szse.cn/institute/rules/t20200807_580310.html)、[主板与创业板 ST 限制差别](https://www.szse.cn/www/investor/knowledge/stock/deal/t20210127_584469.html)。IPO 首五日、重新上市等特殊无涨跌幅限制日未建模，单独审计超出推算限价的行，不据此删股票。
- CLI 未来区间闸门：直接拒绝 `end >= 2026-07-06`，在创建目录或登录前失败；不把旧主板 ST 5% 规则延伸到新制度。依据：[深交所 2026 交易规则通知](https://investor.szse.cn/lawrules/rule/trade/t20260424_620190.html)、[上交所 2026 交易规则通知](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)。本闸门不改变 2023—2025 数据。
- `data.py` 把 JSON 安全的源 `attrs` 存入 `source_metadata`，同时保留 `provider/data_limitations/execution_semantics`，不会因复制快照丢掉 `derived_limits` 及其他限制。
- 缓存、下载文件拒绝符号链接逃逸；快照禁止覆写、独立哈希验证，运行时不需要读取原始下载缓存。
